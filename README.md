# Lime, Slurry & Fertiliser Farm Planner — Version 4

This is a single-file build.

Only `index.html` is required. CSS and JavaScript are embedded in the same file, so an older cached `app.js` cannot leave the score table stuck at six rows.

The score table has seven permanent rows:
1. Lime requirement
2. Lime/slurry timing
3. Well-drained spring N plan
4. Slurry inventory
5. First-cut silage
6. Silage timing
7. Practice generator

The Practice Generator is visible immediately and generates a case automatically on page load.

For GitHub Pages, replace the existing `index.html` with this file.
